# VidaSim - Life Simulator

A modern, mobile-first life simulator game where your choices shape your destiny.

## Features

### 🎮 Gameplay
- **Age Progression**: Start at 18 and live year by year
- **Dynamic Events**: Experience random life events across 9 categories
- **Meaningful Choices**: Make decisions that affect your future
- **Attributes**: Manage Health, Mood, Money, and Reputation
- **Shop System**: Buy cars and phones to boost your status
- **Rarity System**: Common, Rare, and Epic events with different frequencies

### 🎨 Design
- **Mobile-First**: Optimized for touch devices
- **Dark/Light Theme**: Switch themes in settings
- **Smooth Animations**: Polished transitions and effects
- **Responsive Layout**: Works on all screen sizes
- **Modern UI**: Gradient cards, soft shadows, pleasant typography

### 💾 Technology
- **Pure JavaScript**: No frameworks required
- **LocalStorage**: Automatic game saving
- **No Build Step**: Just open index.html
- **Standalone**: All assets included

## Getting Started

1. Clone or download this repository
2. Open `index.html` in any modern web browser
3. Start playing!

## Game Controls

- **Next Year**: Progress to the next year and trigger new events
- **Shop**: Browse and purchase items (cars, phones)
- **Reset**: Start a new life (clears all progress)
- **Settings**: Customize theme, event density, and animations

## Event Categories

- **Career**: Job opportunities, promotions, layoffs
- **Education**: Courses, scholarships, exams
- **Health**: Gym, injuries, checkups
- **Finance**: Investments, windfalls, expenses
- **Relationship**: Dating, marriage, breakups, children
- **Social**: Parties, viral posts, volunteering
- **Hobby**: Travel, competitions, learning
- **Legal**: Fines, lawsuits, jury duty
- **News**: Market updates, festivals, discoveries

## Settings

- **Theme**: Light or Dark mode
- **Event Density**: Low (1-2), Medium (2-3), or High (3-5) events per year
- **Animation Speed**: Slow, Normal, or Fast
- **Advanced Mode**: Show detailed statistics (coming soon)
- **Language**: English (more languages coming soon)

## Files

- `index.html` - Main HTML structure
- `style.css` - Styling and themes
- `dados.js` - Game data (events, shops, configuration)
- `game.js` - Game logic and state management

## Browser Support
